关于本站

你好，我是 博主，欢迎来到「我的博客」。

这里是我记录思考、分享技术笔记与生活随想的地方。站点前端由原生 HTML/CSS/JavaScript 构建，可部署到 GitHub Pages；注册登录、评论与文章管理由一个轻量后端（Node.js + SQLite）提供。

功能特性

  • Markdown 写作与代码高亮（自研轻量解析器）
  • 标签 / 分类浏览（点选筛选，再点一次取消）
  • 站内全文搜索
  • 深色模式（自动跟随系统 + 右侧悬浮球手动切换）
  • 首屏封面 + 公告气泡
  • 用户系统（账户登录 + 昵称分离，头像菜单，用户中心）
  • 评论 / 回复（管理员审核后发布，全站共享）
  • 管理员可发布、编辑、删除文章
  • RSS 订阅（rss.xml）
  • 文章内嵌视频 / 音频

如何开始写作

登录管理员账号后，进入「用户中心 → 文章管理」，即可新建、编辑、删除文章（正文用 Markdown）。详细的 Markdown 语法见 Markdown 写作指南。
